PriceLabs Analytics
Dashboard

This project focuses on tracking occupancy, pricing performance, RevPAR, and listing-level health in one centralized dashboard. The goal was to give operators a clear, fast view of what is happening across multiple listings, how each unit compares to benchmarks, and which properties need attention before they impact revenue.

The Problem

Managing a portfolio of listings without a unified dashboard creates information overload. Occupancy, pricing, and performance benchmarks were spread across different views, making it difficult to quickly see underperforming units or understand which properties are trending below target. The challenge was to turn fragmented operational data into a single decision-making view that is easy to scan at a glance.

What I Built

01
Portfolio Overview

Designed a high-level dashboard tracking occupancy, benchmark comparison, listing count, and active versus blocked listings.

02
Listing-Level Performance

Built a listing table that highlights occupancy, RevPAR, and status, allowing quick prioritization of properties that need attention.

03
Benchmark Tracking

Created comparison views for actual vs benchmark occupancy, allowing operators to measure performance over multiple date ranges.

04
Revenue & Booking Insights

Added pricing and booking visuals to review base pricing, recommended base pricing, and 30-day booking pickup against revenue goals.

Tools Used

PriceLabs Dashboard Design Data Visualization Portfolio Analytics Revenue Monitoring

Outcome
